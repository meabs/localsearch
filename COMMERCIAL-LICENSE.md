# Commercial Licensing

The public repository is available under `PolyForm Noncommercial 1.0.0`.

That means:

- personal, research, hobby, educational, and other noncommercial use is allowed under the public
  license
- commercial use is not granted by the public repository license

## Commercial Use

If you want to use this project in a product, internal commercial workflow, paid service, client
delivery, or any other commercial setting, you need a separate written commercial license from the
licensor.

## Attribution Expectation For Commercial Use

Commercial licenses for this project are intended to require clear attribution to the original
project author and repository.

Recommended attribution format:

```text
Powered by Operation Lens v2
Source: <repository URL>
Author: <your name or organization>
```
